# 🧬 Dataset Quality Analyzer

A powerful **Dataset Quality Analyzer** built using Python and Streamlit that automates data validation and quality checks.
This tool helps organizations and data professionals ensure their datasets are clean, consistent, and ready for analytics and AI/ML applications.

---

## 🚀 Features

* 📊 Automated dataset quality assessment
* 🔍 Missing value detection
* 📉 Outlier detection
* 🧹 Data consistency validation
* 📑 Summary statistics generation
* ⚡ Fast and user-friendly Streamlit interface
* 📂 Supports CSV dataset uploads

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **Pandas**
* **NumPy**
* **Matplotlib / Seaborn**
* **Custom Utility Modules**

## ⚙️ Installation

### Step 1 — Clone the repository

```bash
git clone https://github.com/AnweshaBhadury/Dataset-Quality-Analyser.git
cd Dataset-Quality-Analyser
```

### Step 2 — Create a virtual environment

```bash
python -m venv venv
```

### Step 3 — Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### Step 4 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 5 — Run the application

```bash
streamlit run app.py
```
